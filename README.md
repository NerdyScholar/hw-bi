# Аналитик DWH: ключевые требования и технологии

## Ключевые навыки
### Работа с данными
- Проектирование архитектуры DWH (схемы «звезда», «снежинка»).
- Разработка и оптимизация ETL/ELT-процессов.
- Анализ бизнес-требований и их трансляция в технические решения.
- Валидация данных, мониторинг качества.
- Оптимизация SQL-запросов и хранилищ.

## Инструменты и технологии
### Базы данных
- **Реляционные**: PostgreSQL, Oracle, MS SQL.
- **Колонковые**: Greenplum, Teradata.

### ETL/ELT
- Apache Airflow

### BI-системы
- Tableau, Power BI, Qlik, Metabase.

### ЯП и Big Data
- **Языки**: SQL (обязательно), Python
- **Big Data**: Hadoop, Spark, Kafka.

## Дополнительные требования
- Знание методологий Data Vault, Kimball.
- Работа с метаданными и технической документацией.
- Опыт с инструментами: Git, Jira, Confluence.
- Понимание DevOps-практик (CI/CD, Docker).

## Soft Skills
- Коммуникация с заказчиками и командами разработки.
- Управление проектами (Agile, Scrum).
- Аналитическое мышление, внимательность к деталям.

## Опыт работы
- От 1–3 лет в роли аналитика DWH, ETL-разработчика или BI-аналитика.
- Участие в полном цикле создания DWH (от требований до внедрения).
- Опыт в доменных областях: финансы, ритейл, логистика.

## Тренды
1. **Технологический стек**:  
   Акцент на SQL, облачные DWH (Snowflake, BigQuery) и ETL-инструменты.
2. **Навыки**:  
   Интеграция Big Data, работа с KPI для бизнес-аналитики.
3. **Дополнительный плюс в копилку кандидата**:  
   Сочетает техническую экспертизу с пониманием бизнес-процессов.
